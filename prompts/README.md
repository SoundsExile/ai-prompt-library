# AI Prompt Library

> Professional, ready-to-use prompt templates for ChatGPT, Claude, Midjourney, Stable Diffusion, and more.

## Overview

This library contains **200+ curated prompt templates** across 6 categories. Each template is designed to produce high-quality output with minimal editing. Simply copy, customize, and use.

## Categories

| Category | Description | Templates |
|----------|-------------|-----------|
| [Marketing Copy](marketing.md) | Ads, landing pages, taglines, product blurbs | ~40 |

| [Image Generation](image.md) | Midjourney, SD, DALL-E prompts | ~45 |

## How to Use

1. **Browse** the category that matches your need
2. **Copy** the prompt template
3. **Customize** bracketed items like `[product name]` or `[audience]`
4. **Run** in your AI tool of choice
5. **Refine** based on output quality

## Format

Each template uses this structure:

```
---
**Prompt:** [Your instruction here]
**Context:** [Optional background]
**Output:** [Expected format, length, tone]
---
```
